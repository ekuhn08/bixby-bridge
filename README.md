# Bixby Bridge – Motion Graphic & Ocean Shimmer Animation

A light-weight web animation project utilizing HTML5 Canvas, CSS, and JavaScript to apply localized motion and shimmer effects over a masked still image of Bixby Bridge. 

This repository serves as a modular component designed to be hosted independently or integrated into a primary master website as a subpage.

---

## 🌟 Overview

* **Project Type:** Motion Graphics / Interactive Web Animation
* **Techniques Used:** Image Masking, Layered Motion, HTML5 Canvas, CSS Animation
* **Primary File:** `bixby-bridge-motion-project.html`
